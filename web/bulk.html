Check many labels at once

Give the tool a spreadsheet listing your products, plus the label pictures. It checks every row and gives you a results file you can open in Excel.

How this works

  1. Download a information filled spreadsheet Ensure the label's 1st image file name you upload, matches the spreadsheet image column, that holds the picture's file name. If a product has a back label as well, put its file name in the image_2 column and make sure it matches as well.
  2. Choose the spreadsheet below.
  3. Choose all the label pictures together. They are matched to the rows by file name.

Your spreadsheet
It must have a heading row and an image column. An image_2 column for back labels is optional.
Your label pictures
Select them all at once. Hold Ctrl (or Command on a Mac) to pick more than one.

Nothing is uploaded. Your spreadsheet and pictures stay on this device. All the checking happens inside your web browser.
