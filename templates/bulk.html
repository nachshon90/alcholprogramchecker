Check many labels at once

Give the tool a spreadsheet listing your products, plus the label pictures. It checks every row and gives you a results file you can open in Excel.

How this works

  1. Download a information filled spreadsheet Ensure the label's 1st image file name you upload, matches the spreadsheet image column, that holds the picture's file name. If a product has a back label as well, put its file name in the image_2 column and make sure it matches as well. – both pictures are then checked together as one container. Leave image_2 empty for products with a single label.
  2. Put all the label pictures in one folder, then make a ZIP file of that folder.
  3. Send both files using the boxes below.

Download the blank spreadsheet

Your spreadsheet

Your label pictures
This is the usual way. The pictures may sit in folders inside the ZIP.

For example: /home/jane/labels
